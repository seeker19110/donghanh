# Lint file `.cjs` thật, khai đúng CommonJS

- **Ngày:** 2026-09-26 · **PR:** PR của nhánh `seeker/zealous-allen-ygj0gw` (sau #1180)
- **Loại:** `build(lint)`. Người dùng giao "tự quyết cho chất lượng cao" các việc còn chờ quyết.
  Đây là việc nhỏ nhất trong danh sách: nợ (3) của đợt nâng cấp stack (`0414`).

## Vì sao

Cấu hình ESLint cũ chạy `eslint . --ext ts,tsx,js,mjs`, nên `commitlint.config.cjs` và
`ecosystem.config.cjs` (cấu hình PM2 chạy production) **chưa bao giờ được lint**. Khi chuyển sang
flat config, `**/*.cjs` được đưa vào `ignores` để đợt chuyển không lặng lẽ đổi phạm vi, kèm ghi chú
"làm ở PR riêng". Đây là PR đó.

## Đã làm

- Bỏ `**/*.cjs` khỏi `ignores` trong `eslint.config.js`.
- **Phát hiện kèm:** flat config parse `.cjs` như **ES module** (`sourceType: module`), trong khi
  đây là CommonJS thật (PM2 và commitlint đọc bằng `require`). Thêm khối cho `**/*.cjs` với
  `sourceType: 'commonjs'`, và tắt `@typescript-eslint/no-require-imports` vì `require` là cách
  import chuẩn của CommonJS.

## Bằng chứng

- `npx eslint --print-config ecosystem.config.cjs`: `sourceType: commonjs`, 127 luật bật.
- Hai file `.cjs` thật qua lint (0 lỗi, 0 cảnh báo).
- Chống xanh giả: file thử `.cjs` có biến không dùng bị bắt đúng lỗi
  `@typescript-eslint/no-unused-vars`, chứng tỏ `.cjs` nay được lint thật.
