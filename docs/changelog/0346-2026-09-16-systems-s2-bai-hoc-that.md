# Hệ thống S2 có bài học thật

- Thêm bốn unit, tám bài Python tương tác về process/concurrency, file/durability, TCP/event loop
  và ownership/safety contract của Rust.
- Mỗi bài chạy simulator tất định với ca hiện, ca ẩn và ca biên; luôn phân biệt rõ với Linux,
  socket, C và Rust toolchain thật.
- Nối `systems-s2` vào trang hướng Hệ thống, lazy registry và các cổng semantic/Python/E2E.
- Giữ nguyên rubric shell, server 1000 kết nối, leak và atomic write để nghiệm thu ngoài sandbox.
